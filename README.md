## Objetivo
Repositório criado para organizar projetos acadêmicos e pessoais, praticar versionamento com Git/GitHub e apresentar uma página pública de portfólio.

## Estrutura
- `github-pages/` — página publicada pelo GitHub Pages.
- `projetos/` — espaço para projetos acadêmicos e pessoais.
- `documentacao/` — documentos e informações dos projetos.
- `README.md` — documentação principal.

## Versionamento
Versão inicial: **1.0**.  
Após alterações no site, deve ser criado um novo commit e enviado ao GitHub.

## Git
Comandos principais:
```bash
git init
git add .
git commit -m "Versão 1.0 - criação do PortfolioHUB"
git branch -M main
git remote add origin URL_DO_REPOSITORIO
git push -u origin main
```

## GitHub Pages
No GitHub: Settings → Pages → Deploy from a branch → `main` → pasta `/github-pages` (ou raiz, conforme a configuração escolhida).

## LinkedIn
Depois da publicação, adicionar o projeto ao perfil do LinkedIn na seção de projetos e inserir o link do repositório e da página.

## Observação
Os campos de usuário do GitHub e LinkedIn precisam ser substituídos pelos links reais do aluno.
